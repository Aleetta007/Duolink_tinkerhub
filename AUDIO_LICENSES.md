## Notes

- No copyrighted Malayalam movie dialogue audio is included in this repository.
- All parody recordings are original works created by the project team.
- The application gracefully handles missing audio files — it continues to function if any sound file is absent.
- Sound files should be added to `public/sounds/` before deployment.

## Adding Audio Files

To add sound effects:

1. Record or source audio files that you have the right to use.
2. Place them in `public/sounds/` with the exact filenames listed above.
3. Update this file with the appropriate license information.

**Do not add copyrighted audio without proper licensing.**
