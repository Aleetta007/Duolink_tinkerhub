# sounds/

Place audio files here for the Kozhitharam Detector™ sound system.

Expected files:

- scan-start.mp3
- face-detected.mp3
- analysis.mp3
- low-score.mp3
- medium-score.mp3
- high-score.mp3
- extreme-score.mp3

The application works without audio files — missing sounds are silently ignored.

See AUDIO_LICENSES.md in the project root for licensing requirements.
